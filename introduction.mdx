## Getting Started

To begin using Igor Gnot Documentation, sign up for an account and explore the dashboard. You can create your first document within minutes and start collaborating immediately.

<CodeGroup tabs="JavaScript,Python">
  ````javascript
  // Initialize Igor Gnot Documentation client
const client = new IgorGnotClient({
  apiKey: 'your-api-key'
});

// Create a new document
client.createDocument({
  title: 'My First Document',
  content: 'Welcome to Igor Gnot!'
});
  ````
  ````python
from igor_gnot import Client

# Initialize client
client = Client(api_key='your-api-key')

# Create document
document = client.create_document(
    title='My First Document',
    content='Welcome to Igor Gnot!'
)
  ````
</CodeGroup>
