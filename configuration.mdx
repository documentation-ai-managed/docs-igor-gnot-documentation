## Workspace Configuration

Set up your Igor Gnot workspace with basic settings. You define the workspace name, default language, and access controls.

<Steps>
  <Step title="Access Settings" icon="settings">
    Navigate to Admin > Workspace Settings.
  </Step>
  <Step title="Set Workspace Name" icon="edit">
    Enter a descriptive name for your workspace.
    
    <CodeGroup tabs="JSON,YAML">
      ````json
      {
        "workspace": {
          "name": "My Team Docs",
          "language": "en",
          "timezone": "UTC"
        }
      }
      ````
      ````yaml
      workspace:
        name: My Team Docs
        language: en
        timezone: UTC
      ````
    </CodeGroup>
  </Step>
  <Step title="Configure Permissions" icon="shield">
    Define default access levels for new members.
  </Step>
</Steps>

## Environment Variables

Use environment variables for sensitive configuration. You keep secrets secure and environment-specific.

<CodeGroup tabs="Shell,Docker">
  ````bash
  export IGOR_GNOT_API_KEY="your-secret-key"
export IGOR_GNOT_DATABASE_URL="postgres://user:pass@host/db"
export IGOR_GNOT_DEBUG="false"
  ````
  ````dockerfile
  ENV IGOR_GNOT_API_KEY=your-secret-key
ENV IGOR_GNOT_DATABASE_URL=postgres://user:pass@host/db
ENV IGOR_GNOT_DEBUG=false
  ````
</CodeGroup>

<Steps>
  <Step title="Set Variables" icon="terminal">
    Define environment variables in your deployment.
  </Step>
  <Step title="Restart Service" icon="refresh-cw">
    Restart Igor Gnot to pick up new variables.
  </Step>
  <Step title="Verify Configuration" icon="check-circle">
    Check logs to confirm settings are applied.
  </Step>
</Steps>

<Callout kind="tip">Use a secrets manager like AWS Secrets Manager for production environments.</Callout>
