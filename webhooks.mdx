## Understanding Webhooks

Webhooks send HTTP POST requests to your specified URL when events happen in Igor Gnot Documentation. You process these payloads to trigger actions in your systems.

<Steps>
  <Step title="Choose Events" icon="list">
    Select which events you want to monitor.
  </Step>
  <Step title="Set Endpoint URL" icon="link">
    Provide a secure HTTPS URL to receive webhooks.
    
    <CodeGroup tabs="Node.js,Python">
      ````javascript
const express = require('express');
const app = express();

app.post('/webhook', (req, res) => {
  const payload = req.body;
  console.log('Received webhook:', payload);
  res.sendStatus(200);
});

app.listen(3000);
      ````
      ````python
from flask import Flask, request

app = Flask(__name__)

@app.route('/webhook', methods=['POST'])
def webhook():
    payload = request.json
    print('Received webhook:', payload)
    return 'OK', 200

if __name__ == '__main__':
    app.run(port=3000)
      ````
    </CodeGroup>
  </Step>
  <Step title="Test Webhook" icon="check-circle">
    Send a test payload to verify your endpoint.
  </Step>
</Steps>

## Security and Authentication

Secure your webhooks with proper authentication. You verify incoming requests to prevent unauthorized access.

| Method | Description | Security Level |
|--------|-------------|----------------|
| HMAC Signature | Cryptographic signature | High |
| API Key | Shared secret key | Medium |
| IP Whitelist | Restrict by IP address | Low |

<Callout kind="alert">Always use HTTPS URLs and verify webhook signatures to ensure security.</Callout>

  ````go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"fmt"
)

func verifySignature(payload, signature, secret string) bool {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(payload))
	expected := hex.EncodeToString(mac.Sum(nil))
	return hmac.Equal([]byte(signature), []byte(expected))
}
  ````
  ````ruby
require 'openssl'

def verify_signature(payload, signature, secret)
  digest = OpenSSL::Digest.new('sha256')
  expected = OpenSSL::HMAC.hexdigest(digest, secret, payload)
  Rack::Utils.secure_compare(signature, expected)
end
  ````
</CodeGroup>
